## Push to GitHub

1. Initialize a Git repository:

```bash
git init
```

2. Add files:

```bash
git add .
```

3. Commit the project:

```bash
git commit -m "Initial portfolio website"
```

4. Create a remote repository on GitHub and add it:

```bash
git remote add origin https://github.com/yourusername/aj-techlab-portfolio.git
```

5. Push to GitHub:

```bash
git push -u origin main
```

If your default branch is `master`, replace `main` with `master`.
